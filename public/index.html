Kenapa muncul "URL tidak valid"?
Pastikan URL mengandung whatsapp.com/channel/ dan ada ID postingan di belakangnya. Link dari profil channel, bukan postingannya, tidak diterima.
Berhasil tapi reaksi tidak muncul di WA?
Kadang ada delay dari sisi WhatsApp. Refresh postingannya setelah beberapa detik. Kalau tetap tidak muncul, session API mungkin sedang bermasalah.
Limit habis, bisa di-reset manual?
Tidak bisa. Counter reset otomatis tiap tengah malam (00:00). Coba lagi keesokan harinya.
Bisa lebih dari 5 emoji sekaligus?
Tidak. Maksimal 5 emoji per submit — kelebihan otomatis dipotong. Ini batas dari API upstream.
Apakah tool ini aman?
Tool ini hanya mengirim reaksi ke postingan publik. Tidak ada data akun WhatsApp kamu yang diproses.
