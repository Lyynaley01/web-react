# WA Reaction - WhatsApp Channel Auto React

> Kirim reaksi ke postingan WhatsApp Channel publik dengan mudah! 🚀

## ✨ Fitur

- ✅ Kirim reaksi (emoji) ke postingan WhatsApp Channel
- ✅ Support maks 5 emoji per submit
- ✅ Free limit 3x/hari per IP (tanpa login)
- ✅ VIP system dengan credit (tanpa limit harian)
- ✅ Firebase Firestore sebagai database
- ✅ Admin dashboard untuk manage VIP keys

## 🛠️ Tech Stack

- **Backend**: Node.js + Express
- **Database**: Firebase Firestore
- **Frontend**: HTML + CSS + JavaScript (Vanilla)
- **Authentication**: Basic Auth + Admin Secret
- **API**: Nexadev API
